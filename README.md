## About Argon PC

Argon PC provides a Windows desktop environment for executing Roblox Lua scripts. Its uncluttered layout is built for common scripting tasks, allowing users to find, load, and execute scripts from a compact workspace.

Alongside Lua execution, the application offers a script hub containing more than 500 entries, support for running actions in batches, and debugging utilities for reviewing script behavior. Auto-update functionality and multiple interface languages are also included for users running the tool on 64-bit Windows 10 or Windows 11 systems.

**Which operating systems can run Argon PC?**  
Argon PC is intended for 64-bit Windows 10 and Windows 11 systems.

**Can the executor adapt when Roblox is updated?**  
The application provides auto-update support intended to help the desktop build remain aligned with newer releases.

**What does Argon PC include compared with similar executors?**  
Its focus is on bringing together a compact Windows interface, Lua execution, a script hub, batch processing, and debugging tools.

**Could using a script executor create account-related risks?**  
Use remains subject to Roblox terms and the user's responsibility. This repository provides no guarantees regarding account safety.

**Can queued scripts be retained?**  
Yes. Persistent queue storage allows script lists and queued items to remain available between application sessions.
